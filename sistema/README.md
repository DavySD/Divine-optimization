## Por que não o Windows

* Esta documentação é pensada para sistemas Unix (Linux). 
* Windows é muito limitado quanto a modificações realmente relevantes.
* Aqui vamos além de desativar animações ou somente adicionar swap, o foco são conceitos como governors de CPU, kernel, compilação, zram/zswap, cache e mais.

## Distribuições

* "Qual distribuição Linux eu escolho?" — Depende muito. No geral, escolha algo como [Linux Mint](https://www.linuxmint.com/). Se seu computador rodar KDE bem, considere [Fedora KDE](https://kde.fedoraproject.org/) ou [CachyOS](https://cachyos.org/). **O que for abordado aqui funciona para 98% das distros.**

> [!NOTE]
> Mais à frente é abordada a distribuição Gentoo. Em hipótese alguma ela é recomendada para iniciantes.
