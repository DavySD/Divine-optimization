Uma documentação e guia de vastas formas nefastas de otimizar um sistema operacional Linux.

---

> [!NOTE]
> Este é um guia em constante evolução. Tópicos marcados com `()` são trabalho em progresso (WIP).
> Se você já domina determinado conceito, sinta-se livre para ir direto ao ponto — *mas sempre leia as entrelinhas.*

## Sobre

* O intuito deste guia é ensinar como tirar mais proveito do hardware a partir do software.
* Ele não faz milagres: mesmo com o melhor modelo de otimização, o gargalo é o hardware.
* O nome é inspirado na [*Divina Comédia*](https://pt.wikipedia.org/wiki/Divina_Comédia) — não porque o guia é engraçado, mas porque você descerá aos infernos aqui.
